## 1. Executive summary

The platform has grown to **21 services, 16 role portals with every catalog section wired to a real screen, ~700+ tests, Keycloak genuinely retired and identity-service genuinely issuing OIDC tokens**, plus phase 12/13 code present. Discipline remains exceptional: zero TODO/FIXME, essentially zero analyzer suppressions, DB-level idempotency, real hash-chained WORM audit, min-necessary tests in 12 services, ESLint + zod boundary parsing now landed, and CI that actually runs Postgres.

**Three themes define what is left.**

**Theme 1 — R1 remediation is 70% real, but three closures do not hold.** The outbox is durable but **not transactional** (enqueue is a second `SaveChanges` after the business commit — a crash between them still loses the event, so Invariant 3 is not yet guaranteed). The secrets purge **regressed**: two new committed credentials appeared, including the MinIO key for the PHI blob bucket. The RLS retrofit shipped for 13 services but **4 still connect as the superuser** (including provider, the reference implementation) and **3 have RLS DDL with no GUC binder** — a deny-all trap armed and waiting.

**Theme 2 — the platform's benefit logic has correctness defects that no test covers.** The most serious: **`coverage_limit.consumed_value` is never incremented by anything** — consume/dispense emit the events, but no consumer applies them — so `remaining` always equals the full limit, `LIMIT_EXCEEDED` can never fire, and **every member is eligible forever**. Alongside it: claim batch rollups **silently erase applied adjustments** at the moment totals are frozen for settlement; the allowed-amount cap uses `Math.Max` instead of `Math.Min`, permitting approval **above the contract tariff**; contract price **ignores line quantity**; and concurrent consume of *different* lines is a lost update that can strand an order in `PartiallyUsed` forever. These are money-and-entitlement bugs, not style issues.

**Theme 3 — six last-mile wiring omissions make finished features unreachable, and three CI gates that were claimed are not running.** Live sessions die every **5 minutes** (no refresh-token exchange). Branch scoping is inert end-to-end (the SPA never sends `X-Active-Branch`; Kong's CORS doesn't allow it). Interop/FHIR (phase 13, ticked ✅) has **no compose entry and no Kong route**. The sensitive-result release workflow has no approver UI, so the gate is permanent-deny. Identity admin has no gateway route. The SPA itself is commented out of compose. The route-coverage guard, identity test DB, and OpenAPI generation for the two newest services are all absent from CI — which is precisely how those omissions survived.

**UI/UX:** the design system is faithful to the specs and the v1.1 refinements are correctly implemented — that foundation should be defended. But four write flows **fail silently** (spinner stops, no message, no idempotency key — the operator's rational response is to retry, creating duplicate clinical records); all 4xx classes collapse into one generic message on decisions/dispense/consume; the Call Centre renders **every member status as a green "eligible" chip**; navigation **disappears entirely below 760px**; and the app-bar global search is a dead field bound to the `/` shortcut.

**Verdict:** this is a strong, near-complete build whose remaining risk is concentrated, not diffuse. Nothing needs rebuilding. What is needed is: fix the benefit-logic correctness bugs, finish engaging the security layers, connect six wires, and make CI enforce what it claims.

## 3. High findings

**Security** — **S1** ✅ 2026-07-27 provider-service (the RLS reference implementation) still runs as superuser, so its green isolation tests prove the policy, not the deployment (`compose.yaml:424`). **S2** ✅ 2026-07-27 interop's RLS policy is the only fail-**open** one in the repo (`OR current_setting(...) IS NULL`) and its GUC is never bound. *(18.B2 correction: not the only one — admin's 0001/0002/0003/0004 carry the same escape, which interop 0001 cites as its precedent. All closed together.)* **S3** ✅ 2026-07-27 C3 unchanged — every admin privileged group is still un-gated at the framework (`UsersEndpoints.cs:15` et al.), **so no MFA on role grants, de-provisioning or break-glass** — and the same pattern was replicated into identity (`AdminEndpoints.cs:27`) and interop. **S4** ✅ 2026-07-27 CSRF on the identity issuer's cookie POSTs including `POST /connect/enroll-2fa` (`AccountPages.cs:75` `.DisableAntiforgery()`) — a cross-site post registers *the attacker's* authenticator as the victim's second factor; cookies lack `Secure`/`SameSite=Strict`. **S5** ✅ 2026-07-27 token scope grant **fails open**: `TokenPrincipalFactory.cs:37-40` grants the user's *entire* entitlement when the requested scopes don't intersect. **S6** ✅ 2026-07-27 patient-service by-id/search returns full DTO **including national ID and contacts** with no row-scope, no engine call and **no PHI-read audit** (`patient/Api/Program.cs:105-133`), still gated on `patient:write`. **S7** ✅ 2026-07-27 identity-service is the only service without `UseHbmpTransportSecurity()` — no HSTS/HTTPS redirect on the token issuer. **S8** ✅ 2026-07-27 Kong still performs **no authentication** (no JWT plugin). **S9** ✅ 2026-07-27 no rate limiting on `/connect/*` — only a global 1200/min per-node Kong rule.

**Correctness** — **X7** ✅ 2026-07-27 aggregate status is a **lost update** under concurrent consume/dispense of *different* lines (`ConsumeExecutor.cs:63,91-92` computes from a stale in-memory graph, writes unguarded) → order stuck `PartiallyUsed`, `OrderCompleted` never emits. **X8** ✅ 2026-07-27 contract price **ignores quantity** (`AutoDerive.cs:33-40`), so a qty-3 line pays one unit and reconciliation flags every multi-unit line as a price variance. **X9** ✅ 2026-07-27 eligibility cache key omits `serviceCode`/`requiresPreAuth` (`EligibilityCache.cs:21`) → a cached non-gated `Eligible` is served for a **gated** service for 15 minutes, bypassing the pre-auth gate. **X10** ✅ 2026-07-27 first-ever limit reset **wipes in-period consumption** (`LimitReset.cs:28-30`) — and the test asserts the buggy behaviour.

**Delivery/wiring** — **W1** ✅ 2026-07-27 live sessions expire every **5 minutes**: `offline_access` is requested but `oidcClient.ts` has no refresh exchange and discards the refresh token. **W2** ✅ 2026-07-27 branch scoping non-functional end-to-end — SPA never sends `X-Active-Branch`, Kong CORS omits it from both `headers` and `exposed_headers`. **W3** interop/FHIR (phase 13 ✅) has **no compose service and no Kong route**; the coverage guard can't see it because it only inspects `/api/v1`. **W4** report-access **grant/decision has no UI** — requests can be raised but never approved, so the sensitive gate is permanent-deny; no scheduler calls the expiry sweep. **W5** identity admin (`/identity/admin/*`, the thing that closes C3) has **no Kong route**; the admin console still edits the legacy projection. **W6** the SPA is **commented out of compose** (`compose.yaml:644`). **W7** FR-BRN-026/027 unbuilt — zero `practitioner` references in emr, so a doctor can be booked at a branch they aren't assigned to. **W8** 10b.6 OCR reimbursement is ticked but structurally cannot auto-process (`ReimbursementSeams.cs:21-71` — null OCR, null resolver, no-op scanner).

**Quality/CI** — **Q1** the Kong route-coverage guard, `IDENTITY_TEST_DB`, and OpenAPI generation for identity+interop are all **claimed but not wired** — identity, the newest and most security-critical service, has **no CI regression gate**. **Q2** GitLab/GitHub split-brain persists (`.gitlab-ci.yml` still the phase-0 stub with an `echo` coverage gate). **Q3** masterdata: 21 endpoints, 1 test file, no authz suite. **Q4** coverage floor is **55%**, not the documented 80%.

**UI/UX** — **U1** four write flows **fail silently** (`ResultUpload.tsx:56`, `BeneficiaryPortal.tsx:179`, `NetworkPortal.tsx:209`, `ApprovalsExtra.tsx:95`) *and* lack idempotency keys → retry creates duplicate clinical records. **U2** all 4xx collapse into one message on decide/dispense/consume — an approver cannot distinguish "a colleague already decided this" (409) from a network blip, and will retry a decision that already landed. **U3** Call Centre renders **every** member status as a green ✓ chip (`CallCentre.tsx:301`) — a Suspended/Expired member reads as eligible. **U4** navigation **vanishes below 760px** with no replacement (`app.css:392`); `NavRail.tsx:22` documents a bottom tab bar that doesn't exist. **U5** the app-bar global search is a **dead field** bound to `/`. **U6** axe covers 3 routes of ~45, zero Arabic/RTL scans, contrast disabled everywhere. **U7** dates/times use browser locale **and browser time zone** — appointment times can display hours off from Africa/Cairo. **U8** undefined CSS tokens in the Call Centre stylesheet (`--brand-teal`, `--radius-2`) silently kill the selection ring; **U9** brand teal used as an avatar surface with white text (~2.2:1, AA fail). **U10** `<dt>/<dd>` outside any `<dl>` in 34 places across 7 screens; worklist rows are focusable but **Enter does nothing**; dashboard charts are `aria-hidden` with the data-table alternative hidden behind a default-off toggle.

## 4. What is genuinely good (defend this)

Consume/dispense **do** compose all three mechanisms correctly in one transaction with DB CHECK backstops; no double-billing (unique `fulfillment_ref`); one-open-batch enforced; appointment double-booking prevented by slot lock + partial unique index; authorization lifecycle is 1:1 with the spec. `decimal` everywhere for money, **zero** `DateTime.Now`. Break-glass now genuinely elevates with a fail-closed provider that correctly beats the null registration; approvals sensitivity gating is closed via a single shared rule. Audit remains hash-chained, WORM-backed, verifier-checked, and immutable at three DB layers. No SQL injection anywhere; no PHI in logs; no stack traces leak. Test integrity is fixed (SkippableFact, real Postgres in CI, real coverage gate). ESLint landed; zod now parses at 62 boundaries. All 21 services follow the house pattern with README + Dockerfile + audit client + durable outbox. Every portal catalog section resolves to a real screen. The design system matches 0A/0B **and** the §10b v1.1 refinements token-for-token, with correct reduced-motion/reduced-transparency handling.

## 5. Enhancement recommendations (market best practice)

**Architecture & quality.** Architecture tests (NetArchTest) encoding the house pattern — *every* `Program.cs` must call `UseHbmpTransportSecurity` + `UseHbmpRls`; every tenant entity must have a matching RLS migration — would have caught 4 of the 6 criticals at build time. Add mutation testing on `libs/authz` + domain; Pact contract tests for FE↔API and interop↔partner; commit OpenAPI specs and **codegen the frontend client from them** (structurally eliminates the 133 `any` in `HttpApiClient.ts`); extract `libs/testing` (13 hand-copied RLS harnesses today); consolidate the 16 `*Gate.cs` into one generic gate.

**Correctness engineering.** Property-based testing over the consume/dispense executors (catches X7 and the idempotency-prefix bug mechanically); a **state-machine conformance test generated from `23-state-machines.md`** asserting both directions (no undeclared transition allowed, every declared state reachable); a `Money` value type with explicit rounding that makes X3 structurally impossible; one canonical `IRollupService` (kills X2 permanently); a `TimeProvider` + `IBusinessCalendar.Today()` in Africa/Cairo, enforced by an analyzer.

**Security.** OpenBao *dynamic* Postgres credentials instead of static `hbmp_app`; **tenant-isolation fuzzing in CI** driven off `information_schema` so a new table without a policy fails the build; streaming **anomaly detection on the audit stream** (break-glass outside change windows, one subject reading >N beneficiaries/hour, exports out of hours); authenticated DAST/API fuzzing with three role tokens asserting 403-not-200 on cross-role resources; SBOM + cosign + SLSA provenance with an admission policy refusing unsigned images.

**UI/UX** (full detail in the phase-18 gates). Highest value: a **command palette** replacing the dead search (the only navigation that scales across 16 role portals); **server-side sort/filter/pagination** on the four high-volume worklists — SLA-remaining sort on approvals is the difference between working a deadline and guessing; **keyboard-first worklist mode** (`j/k`, `Enter`, `a/r/p`, `?`) for throughput-bound approvers and call agents; **typed confirmations for irreversible clinical actions** (today the one `window.confirm` guards the *reversible* export while reject/break-glass/dispense/consume/cancel are unguarded); a single bilingual `writeErrorMessage(ApiError)`; restored mobile navigation; content-shaped skeletons and an offline banner for Egyptian clinic bandwidth; and privacy-safe UX telemetry (no PHI) whose retry-after-failure metric would have surfaced every silent-failure defect above within a week.
