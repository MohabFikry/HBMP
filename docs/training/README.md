# Mersal HBMP — Training & Change Management (Pilot)

Phase 12.3. Role-based, **bilingual (العربية / English)** training for the pilot, plus the provider
onboarding kit (../35 §6). Published to the knowledge base; delivered before users are enabled
(cutover go/no-go item).

## Contents
- [`role-quick-starts.md`](role-quick-starts.md) — quick-start per pilot portal: Reception,
  Registration, Clinician, Nurse, Lab/Imaging, Pharmacy, Approvals.
- [`provider-onboarding-kit.md`](provider-onboarding-kit.md) — external labs, imaging centres,
  pharmacies (order queue, atomic consume, result upload, dispensing).

## Delivery model (change from paper)
- **Sandbox practice** on the dev/QA environment (fixtures, no PHI) before go-live.
- **Champions / super-users** per team support peers on the floor; named at cutover.
- **Floor-walking support** in week 1 (hypercare war-room).
- **Feedback loop:** issues → incident register + backlog; measure adoption (logins, feature usage,
  paper reduction) on the pilot dashboard.

## Accessibility & language
All portals are **WCAG 2.2 AA**, keyboard-operable, and fully **Arabic RTL + English** (layout
mirrors). Screens show status by hue + icon + shape + text (not colour alone). Training mirrors the
in-product bilingual labels.

## Short task videos (storyboards)
Each quick-start below doubles as a **video storyboard** (numbered steps = shots). Record a ≤ 3-min
screen capture per role from these steps (AR and EN narration) and attach to the knowledge-base
article of the same name. Videos are a delivery artifact produced from these scripts at pilot time.
